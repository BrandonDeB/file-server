## What is this Project
A Django-built project designed to help organize and host session for Dungeons and Dragons.
## The Idea
Markdown formatting works very well for tracking characters and sessions. The goal is to move tasks already done
through Obsidian.md and move them over to the web for easier sharing and collaboration.
## Features
+ Django User Authentication
+ File Upload and Download
+ File sharing with other users
+ WebSocket support for live updating of text documents
+ Folders for file organization
+ Rooms for rolling dice with friends
